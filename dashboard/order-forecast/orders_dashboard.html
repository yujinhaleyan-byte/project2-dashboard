매장 주문량 예측 검토

5개 매장 · 전날 영업 종료 후 다음 날 매장별 주문건수 예측(선형회귀) · 교육용 가상 데이터

1. 매장별·요일별 주문 현황 학습 데이터

대상 기간: 2024-11-01 ~ 2026-05-31 (행) · 일평균 주문건수

요약 • 매장 순서: 판교 > 강남 > 잠실 > 양재 > 수원 (판교가 수원의 약 2배) • 모든 매장에서 금~일에 주문이 늘고 토요일이 가장 높음 • 주말 증가폭은 매장마다 다름 (판교·수원 큼, 잠실 작음)

2. 실제 vs 예측 주문건수 평가 데이터

대상 기간: 2026-06-01 ~ 2026-08-31 (460행) · 범례를 클릭하면 매장별로 켜고 끌 수 있습니다 · 점에 마우스를 올리면 상세 확인

요약 • 기준선(예측=실제) 아래가 많음: • 평균 오차 건 → 전반적으로 적게 예측 • 주문이 많은 날일수록 더 낮게 예측 • 잠실이 가장 크게 어긋남
평균 절대오차

3. 오차가 큰 기록 Top 10 평가 데이터

예측오차 = 실제 주문건수 − 예측 주문건수 (양수 = 실제보다 적게 예측)

요약 • 10건 모두 양수: 바쁜 날을 놓친 경우 • 잠실 6건, 판교 3건, 양재 1건 (모두 7~8월) • 반대 방향(많게 예측) 최대 오차는 −128.8건(강남 8/15)으로 크기가 작음

4. 회귀계수 해석 학습 데이터로 학습

다른 입력을 같게 두었을 때 모델의 예측값이 달라지는 정도입니다. 실제 효과가 입증된 것은 아닙니다.

요약 • 영업시간 +1시간 → 예측 약 +21.6건 • 할인율 +10%p → 예측 약 +23.0건 (1%p당 +2.3) • 매장 영향이 가장 큼: 판교 +93.1, 수원 −73.5 • 요일: 토 +32.3 ↔ 월 −20.9

※ 광고예산·공휴일여부는 이번 모델의 입력에서 제외했습니다. 2026-09~10월 데이터는 사용하지 않았습니다.
